Engineering Architecture & Requirement Solutions

Detailed breakdown of how each challenge was solved with high-availability serverless best practices.

1 Strict Date Validation & Calendar Boundaries

Standard JavaScript new Date('2026-02-31') silently rolls over to March 3rd instead of failing. Our custom parseAndValidateDate() performs regex date-component extraction and UTC calendar verification, accurately rejecting impossible dates. It also guarantees startDate ≤ endDate.

2 Defensive Error Handling & Malformed Input

Guards against non-object payloads, strings, or missing bodies. If a client transmits unparsed JSON, it safely catches syntax errors and responds with a clean 400 Bad Request. The entire handler is wrapped in a global exception handler returning 500 Internal Server Error without crashing the worker.

3 Case-Insensitive Query Filtering

Supports GET /api/leave-request?status=pending. Filters case-insensitively and returns all records when no filter is provided. Compatible with both Vercel’s pre-parsed req.query and standard Node req.url.

4 HTTP Compliance & RFC 7231 Headers (405)

Strictly restricts methods to GET and POST. All other methods return 405 Method Not Allowed with the mandatory Allow: GET, POST header.
